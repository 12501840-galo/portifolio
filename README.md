# Portfólio de Guilherme Luiz

Todos os arquivos do projeto ficam na pasta principal: HTML, CSS, JavaScript, imagens, fontes, licenças, scripts e testes.

Abra `index.html` no navegador ou execute `npm start` para acessar `http://127.0.0.1:4173`.

Edite os dados pessoais, os projetos e o formulário em `config.js`. As imagens e fontes são referenciadas apenas pelo nome do arquivo.

`npm run build` valida o site na própria pasta, sem gerar `dist`. Para publicar, use os arquivos estáticos dessa pasta.

O site, o servidor local e a validação funcionam sem `node_modules`. Para executar os testes automatizados, instale as dependências com `npm ci` e execute `npm test`. Os resultados ficam na pasta temporária do sistema. `.git` contém o histórico do repositório.
